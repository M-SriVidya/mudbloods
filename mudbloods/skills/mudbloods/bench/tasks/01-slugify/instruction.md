Create an ES module `src/slugify.js` with a named export `slugify(input, options)`. It turns any string into a URL slug: lowercase, ASCII only (strip accents, so "Crème Brûlée" becomes "creme-brulee"), words joined by a separator, no leading, trailing or repeated separators. `options.separator` defaults to "-". `options.maxLength` (optional) truncates without cutting a word in half and without leaving a trailing separator. Non-string input throws a `TypeError`. Add tests.
