Create an ES module `src/lru.js` exporting a class `LRUCache`. Constructor takes `{ max, ttlMs }`: `max` is a positive integer (throw `RangeError` otherwise), `ttlMs` is optional. Methods: `get(key)` returns the value or `undefined` and marks the key as most recently used; `set(key, value)` inserts or updates and evicts the least recently used entry when over `max`; `has(key)` does not change recency; `delete(key)` returns a boolean; `size` getter; `clear()`. Expired entries (older than `ttlMs` since last `set`) behave as missing and must not count toward `size`. Accept an optional `now` function in the constructor options for testable time. Add tests.
