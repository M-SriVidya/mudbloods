Create a Node CLI `bin/wc.js` (ES module, runnable with `node bin/wc.js`). It prints word frequencies for one or more files, or stdin when no file is given. Words are case-insensitive runs of letters, digits and apostrophes. Output is one line per word, `<count> <word>`, sorted by count descending then word ascending. Flags: `--top N` limits output to N lines (N must be a positive integer, else exit 2 with a message on stderr); `--json` prints a JSON array of `{ "word", "count" }` instead. A missing file prints `wc: cannot read <path>` to stderr and exits 1, but still counts the other files. Put the counting logic in `src/count.js` with a named export `countWords(text)` returning a `Map`. Add tests.
