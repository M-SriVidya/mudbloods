Create an ES module `src/csv.js` with a named export `parseCSV(text, options)`. It parses CSV following RFC 4180: fields separated by `options.delimiter` (default `,`); records separated by `\n` or `\r\n`; a field may be wrapped in double quotes, in which case it may contain delimiters, newlines, and doubled quotes `""` meaning one literal quote. Unquoted fields are returned exactly as written (no trimming). One trailing newline at the end of the input does not create an extra record. Empty input returns `[]`. By default return an array of arrays of strings. With `options.header: true`, use the first record as keys and return an array of objects; a record with a different field count than the header throws an `Error` whose message contains the 1-based record number. An unterminated quoted field throws a `SyntaxError`. Add tests.
