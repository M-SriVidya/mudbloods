Create an ES module `src/calc.js` with a named export `evaluate(expr)` that evaluates an arithmetic expression string and returns a number. Support numbers with optional decimals (`3`, `0.5`, `.5`), the binary operators `+ - * / ^`, parentheses, unary minus (`-3`, `-(2+1)`, `2*-3`), and any whitespace. Precedence: `^` highest and right-associative (`2^3^2` is 512), then `* /`, then `+ -`, all left-associative except `^`. Unary minus binds looser than `^`, so `-2^2` is -4. Division by zero throws a `RangeError`. Empty input, unknown characters, unbalanced parentheses, or a dangling operator throw a `SyntaxError`. Do not use `eval` or `Function`. Add tests.
